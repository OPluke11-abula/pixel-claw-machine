## 🎮 遊戲核心特色

- **零依賴單檔架構 (Zero-Dependency)**：完全寫在單一 `index.html`，純原生 Canvas 2D 渲染與 Web Audio API 方波合成音效。
- **自研 2D 剛體物理引擎**：
  - 天車加速度驅動單擺角速度與阻尼晃動（支援真實甩爪技術）。
  - 圓形剛體、連續碰撞防穿透、膠囊體爪臂實體推擠與物理入洞判定。
- **四大主題機台自由切換**：
  - 🧸 **動物樂園機**：經典入門，適合快速累積金幣。
  - 💖 **可愛夢幻機**：輕盈夢幻，聚集高彈力與漂浮氣球。
  - ⚙️ **鋼鐵機械機**：重裝高難度，充斥鋼鐵巨神與重力磚塊。
  - 🧪 **奇幻軟泥機**：混亂連鎖反應，極高彈跳與連鎖推擠。
- **三層難度階梯與 95 隻飽滿娃娃山**：
  - **頂部表層 (40隻)**：標準初階小型娃娃（$r=8$，重量 $1.0$）。
  - **中部夾層 (35隻)**：特殊功能中型娃娃（$r=11\sim 12$，神秘寶箱、炸彈衝擊波、引力星牽引、氣球浮力漂浮、史萊姆高彈力）。
  - **底部深層 (20隻)**：傳說巨型大娃娃（$r=16\sim 17$，體積大 4 倍，重量高達 $2.8\sim 4.0$），需升級機台才能夾取。
- **🎁 神秘寶箱與 🚜 巨型怪手鏟 (Excavator Mega Scoop)**：
  - **神秘寶箱 (Chest)**：夾出中層閃閃發光的神秘寶箱，立即啟動隱藏能力——下一把爪子變形為超霸氣【🚜 巨型怪手鏟】！
  - **怪手一網打盡**：超寬工業級重裝挖斗與黑黃斑馬紋工程設計，下鏟直接整窩鏟起 3~7 隻娃娃，回程一次全倒進洞口，金幣獎勵大爆發！
  - **商店改造卷**：亦可在商店隨時購買「怪手改造卷 (350🪙)」，隨時享受怪手狂鏟娃娃的極致快感。
- **6 大 RPG 永久機台改裝**：
  - 🧵 **加長繩索**：增加爪子下放最大深度（碰觸底層大娃娃必備）。
  - ⚙️ **升級馬達**：增加基礎爪力 $+20\%$，降低半空滑脫率。
  - ⏳ **操作延時**：延長單局瞄準時間 $+4\text{秒}$。
  - ⚡ **高速齒輪**：提升天車平移與升降速度 $+15\%$。
  - 🧤 **巨型爪**：**關鍵核心改裝**！等比例放大爪子視覺外觀與物理抓取半徑 $+20\%$，能包覆抓取傳說巨型娃娃。
  - 🌟 **幸運星**：補貨時大幅提升稀有與傳說娃娃生成機率。
- **⚡ 二段按鍵提前合爪 (Early Close / Double-Tap Close)**：
  - 徹底告別下爪後只能被動等待的無力感！下降途中按鍵即時變成「🛑 合爪」，隨時再次按下 `Space` 或點擊按鈕，爪子立即在當前深度提前合爪，精準捕捉浮空漂浮氣球、高位耳朵或半空娃娃！
- **🔥 FEVER TIME & 連擊狂熱模式**：
  - 連續獲勝（Combo $\ge 2$）觸發 FEVER 模式！機台招牌燈泡以 2 倍速開啟 6 色彩虹旋轉，頂部跑馬燈閃爍 `FEVER xN`，每隻進洞娃娃額外加贈大量連擊金幣（+25~100🪙）！

  - 🎯 **雷達垂直瞄準線**：精準雷達投射垂直紅色虛線光學雷射，消除視差。
  - ✨ **神爪金光火花**：保夾與強爪狀態下爪臂散發璀璨粒子光暈。
  - 🏆 **13 大成就系統**：新增「狂熱連中」與「福袋大富翁」，包含全收集 21 種娃娃、怪手神人、改裝大師、機台巡禮、金幣大亨等深度成就挑戰。

## 🕹️ 操作方式與快捷鍵

### 經典 2D 版操作
| 動作 | 電腦鍵盤 | 行動裝置 / 觸控面板 |
|---|---|---|
| **投幣 (10元/次)** | `Enter` / `C` | 點擊「投幣 10 元」 |
| **天車左右移動** | `←` `→` 或 `A` `D`（長按加速） | 按住虛擬鍵「◀」/「▶」 |
| **下爪釋放** | `Space` / `↓` | 點擊虛擬鍵「下爪」 |
| **二段提前合爪** | 下降中 `Space` / `↓` | 點擊「🛑 合爪」按鈕 |
| **切換 2 倍速** | `F` 鍵 | 點擊右上「▶ 1X / ⏩ 2X」 |
| **切換機台主題** | 右上角下拉選單 | 右上角下拉選單 |
| **重整機台 (補貨)** | 點擊「🔄 重整機台」 | 點擊「🔄 重整機台」 |
| **靜音開關** | `M` 鍵 | 點擊「🔊 / 🔇」按鈕 |

### 2.5D 等角立體版操作
| 動作 | 電腦鍵盤 | 行動裝置 / 觸控面板 |
|---|---|---|
| **前後深淺移動** | `W` (深入) / `S` (靠前) 或 `↑` `↓` | 點擊 D-pad「▲ 深入」/「▼ 靠前」 |
| **左右水平移動** | `A` (往左) / `D` (往右) 或 `←` `→` | 點擊 D-pad「◀ 往左」/「▶ 往右」 |
| **下爪抓取** | `Space` | 點擊「🎯 下爪抓取」按鈕 |
| **二段提前合爪** | 下降中 `Space` | 點擊「🛑 提前合爪」按鈕 |
| **切換倍速** | `F` 鍵 | 點擊「⏩ 2X倍速」按鈕 |
