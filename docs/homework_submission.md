## 三、 我做了什麼？（想法與規格說明）

### 1. 發想初衷
平常我很愛去夜市或是西門町夾娃娃，但網路上能找到的夾娃娃網頁大部分都超假，點一下就只是跑個預錄好的假動畫，或是純看機率輪盤，根本沒有實際「甩爪」、「卡爪推擠」的手感。這次作業我就想利用 Vibe Coding，做一個「真的有物理碰撞、有單擺甩爪慣性、有娃娃堆」的 8-bit 像素風夾娃娃機。

### 2. 核心功能規格
- **單一檔案純原生寫法**：  
  整個遊戲完全寫在 `index.html` 裡面，畫面用原生 HTML5 Canvas 2D 一點一點畫出來，聲音也是直接用 Web Audio API 用程式碼合成 8-bit 方波音效，完全沒外掛任何 npm 或第三方套件，點開就能順暢跑。
- **真的有物理跟甩爪**：  
  天車移動不是瞬間停住，而是有加速度跟阻尼。天車左右移動時會帶動繩子擺盪，所以可以利用左右晃動的時機按下爪，做出跟夜市一樣的「甩爪」技巧。
- **三層難度堆疊（95 隻娃娃）**：  
  機台裡面塞了滿滿的 95 隻娃娃：最上面是好夾的小娃娃；中間是有特殊效果的中型娃娃（有會爆炸震開旁邊娃娃的炸彈、飄在空中的氣球、還有神秘寶箱）；最底下則壓著超大隻的傳說級巨型 boss 娃娃，沒升級爪子前根本夾不起來。
- **四種主題機台自由換**：  
  右上角隨時可以切換「動物樂園」、「可愛夢幻」、「鋼鐵機械」跟「奇幻軟泥」，每個機台的娃娃外觀跟彈性手感都不一樣。
- **超爽快神道具與二段合爪**：  
  - **二段提前合爪**：下爪後不用傻傻乾等它降到底，下降途中隨時可以再按一次 Space 或按「合爪」按鈕，爪子就會在半空中直接收攏，可以用來截擊浮在半空的氣球或高處娃娃。
  - **神秘寶箱 ➔ 巨型怪手**：夾到神秘寶箱的話，下一把爪子會直接變形為超大台的怪手鏟子，下鏟一次鏟起 3~7 隻娃娃，回程全部倒進洞口超爽。
  - **彩虹福袋**：夾到福袋進洞會直接爆開噴出兩百多枚金幣跟滿螢幕煙火。
  - **連擊狂熱 (FEVER)**：連續夾中兩次以上會進入 FEVER 模式，頂部跑馬燈會彩虹狂閃，賺到的金幣會加倍。
- **RPG 改裝與存檔經濟圈**：  
  夾到重複的娃娃可以在娃娃櫃一鍵賣掉換金幣，金幣可以拿去商店升級「巨型爪（才能包住大娃娃）」、「加長繩索」、「加大馬達抓力」等能力。如果運氣真的很背，投滿 300 元也會觸發保夾，爪子會發金光保證抓起。

## 四、 跟 AI 討論與反覆修改的過程（Vibe Coding 心得）

這次開發完全體會到 Vibe Coding 的威力，但也經歷了蠻多來回除錯跟打磨的過程：

1. **一開始把想法跟 AI 討論**：  
   我先跟 AI 說想做一個像素風的夾娃娃機，要有真的物理手感跟甩爪。AI 很快幫我把規格整理出來，列出狀態機流程（投幣 ➔ 瞄準 ➔ 下爪 ➔ 合爪 ➔ 回程 ➔ 結算）。
2. **踩雷 1：娃娃開場直接大噴發**：  
   第一次讓 AI 產生 95 隻娃娃時，剛開場因為幾十隻球擠在一起互相排斥，直接像爆米花一樣炸開，好幾隻彈出擋板掉進洞口（不用投幣就狂中獎）。我跟 AI 說「這樣台主直接破產」，後來 AI 幫我修改成：遊戲啟動時先在背景預先模擬沉降幾百步，讓娃娃自然沉成漂亮的斜坡山丘，並且在擋板頂端加上防翻倒鉤，才徹底解決這個 Bug。
3. **踩雷 2：大娃娃根本包不住**：  
   原本底層放了直徑很大的傳說娃娃，但我下爪後發現，普通爪子合起來時半徑太小，直接被大娃娃圓弧頂部推開，完全抓不到。後來我請 AI 在商店加入「巨型爪」升級項目，升級之後不只畫面上的爪子等比例放大，物理判定的膠囊體也一起變大，終於可以把大貓咪抓起來。
4. **手感微調：加入二段合爪與 FEVER**：  
   原本玩了幾局覺得下爪後只能乾等爪子降到底有點無聊，我就叫 AI 加上「下降途中再按一次 Space 可以半空合爪」的功能，結果手感大幅提升，甚至能抓飄在空中的氣球。接著又覺得連續夾中應該要有獎勵，就讓 AI 加了 FEVER 連擊彩虹跑馬燈跟福袋爆獎，整台機台的街機感就出來了。
5. **挑戰極限：自己敲出 2.5D 立體透視版**：  
   平面 2D 搞定之後，我覺得還可以更酷，就叫 AI 幫我寫一個 2.5D 等角透視的立體版（`prototype_25d.html`）。立體版最痛苦的是「看不準深度」，爪子常常抓空。我和 AI 討論後，讓 AI 寫了一個「動態高度陰影演算法」，爪子在移動時，影子不會死死貼在地板，而是會直接吸附在下方娃娃堆的頭頂上，還配了一條垂直的紅外線瞄準虛線，瞬間讓空間對位變得超好抓！
6. **總結**：  
   以前自己寫程式可能光刻一個物理引擎跟畫布就要卡好幾天，這次透過 Vibe Coding，我可以把精力放在「怎樣玩才爽、怎樣才像夜市機台、視覺回饋夠不夠帥」，讓 AI 負責實作數學跟程式碼，遇到手感不好或物理穿透的地方再反覆叫它調整，最後做出這個完成度超高的作品，真的很有成就感！
