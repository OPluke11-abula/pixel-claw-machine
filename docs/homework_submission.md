## 三、 想法與規格文字說明

### 1. 發想初衷
平常我很喜歡去夜市或是夾娃娃機店玩，但網路上大部分的夾娃娃網頁都非常假，點一下就只是跑預錄動畫或純粹抽籤算機率，完全沒有現實中甩爪、推擠入洞的手感。所以這次作業我想透過 Vibe Coding，做出一款真正具有剛體物理碰撞、單擺甩爪慣性與立體娃娃堆的 8-bit 像素夾娃娃機。

### 2. 核心功能規格
- 單一檔案純原生架構：
  整個遊戲完整包在單一 index.html 檔案中。畫面使用原生 HTML5 Canvas 2D 逐幀像素繪製，音效使用 Web Audio API 透過程式動態合成 8-bit 方波聲音，完全沒有引用任何外部 npm、React、Vue 或 Matter.js 等第三方套件，網頁點開就能順暢運行。

- 真實物理與單擺甩爪：
  天車移動具備加速度與阻尼。左右移動天車時，繩索與爪頭會產生擺盪慣性，玩家可以利用晃動時機下爪，做出跟夜市一樣的甩爪技巧。

- 三層難度堆疊與 95 隻娃娃：
  機台內堆滿了 95 隻娃娃。表層為容易抓取的小型娃娃；中層為具有特殊機制的中型娃娃（包含會爆炸震開周遭的炸彈、浮在空中的氣球、神秘寶箱與福袋）；底層則壓著體積大四倍的傳說級巨型 boss 娃娃，需要升級爪子尺寸才有辦法包覆抓起。

- 四大主題機台自由切換：
  隨時可以在右上角切換「動物樂園」、「可愛夢幻」、「鋼鐵機械」與「奇幻軟泥」，每個機台的娃娃外觀、彈性與重量手感皆不同。

- 二段提前合爪：
  下爪後不必乾等爪子降到底部。在下降途中隨時可以再次按下 Space 鍵或點擊合爪按鈕，爪子就會在當前深度立即收攏，可用於半空中攔截浮空漂浮氣球或高處娃娃。

- 特殊道具與爆獎機制：
  夾出神秘寶箱後，下一局爪子會變形為超寬的工業怪手鏟斗，一口氣鏟起 3 到 7 隻娃娃回程倒進出貨口；夾出彩虹福袋進洞會直接引爆大量金幣獎勵。

- RPG 機台改裝與經濟循環：
  夾到重複的娃娃可以在圖鑑中一鍵出售換成金幣，金幣可以用來升級爪子尺寸、馬達抓力、繩索深度與瞄準時間。累積投幣滿 300 元也會觸發保夾機制，爪子會保證抓取回巢。

## 四、 跟 AI 討論與反覆修改的過程 (Vibe Coding 心得)

這次開發完整體驗了 Vibe Coding 的流程，從發想到完成經歷了多次來回溝通與除錯：

1. 一開始把想法跟 AI 討論：
   我先跟 AI 說明我想做一個有真實物理手感、可以甩爪的像素夾娃娃機。AI 協助我梳理狀態機流程，把投幣、瞄準計時、下爪、收爪判定、回程與出貨結算的邏輯架構化。

2. 踩雷一：開場娃娃劇烈排斥並噴出洞口：
   最初生成 95 隻娃娃時，因為剛開場大量球體擠在同一個空間，物理排斥力瞬間爆發，許多娃娃直接彈飛越過擋板掉進洞口，導致不投幣就免費中獎。我和 AI 討論後，在遊戲初始化時先在背景預先模擬沉降數百步，讓娃娃自然沉成穩定的斜坡山丘，並在壓克力擋板頂端加上水平倒鉤防翻線段，徹底解決了溢出問題。

3. 踩雷二：底層大娃娃無法夾取：
   實測時發現底層的大娃娃因為半徑過大，普通爪子合攏時無法包裹其重心，反而會被大娃娃頂開滑落。我和 AI 討論後在商店加入了巨型爪升級選項，升級後爪子的繪圖尺寸與物理膠囊體碰撞範圍等比例放大，終於可以成功包覆抓起巨型娃娃。

4. 操控手感優化：
   原本下爪後只能被動等待爪子落地，玩起來節奏稍慢。我請 AI 加上「下降途中再按一次按鍵即可手動提前合爪」的功能，讓玩家能主動抓取半空中的漂浮氣球。此外也加入了連續夾中的 FEVER 狂熱連擊加成，讓街機回饋感大幅提升。

5. 挑戰 2.5D 等角透視立體版：
   在平面 2D 完成後，為了進一步提升空間感，我和 AI 另外打造了 2.5D 等角透視立體版 (prototype_25d.html)。立體視角最大的難題是深度容易產生視覺誤差，往往看似對準卻夾空。我和 AI 討論後設計了「動態高度自適應陰影演算法」，爪子移動時，陰影不會貼死在地面，而是會自動吸附在下方娃娃堆的最高頂部表面，並搭配垂直紅色瞄準虛線，大幅改善了 3D 空間中的落點判斷。

6. 總結：
   以前寫程式如果遇到複雜的剛體碰撞和數學投影往往要卡關很久。透過 Vibe Coding，我可以將專注力放在玩法機制、遊戲手感與互動體驗上，讓 AI 負責實作數學矩陣與物理計算，遇到不順暢的地方即時請 AI 調整修正，最終完成了這個完整度很高的作品。
