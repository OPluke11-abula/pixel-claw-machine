## 2. 幾何空間與座標投影模型

### 2.1 等角投影（Isometric 2:1 Projection）
將 3D 空間世界座標 $(X, Y, Z)$ 映射至 Canvas 2D 螢幕座標 $(S_x, S_y)$：
- $X \in [-76, +76]$：水平左右軸（向右為正）
- $Z \in [-56, +56]$：深淺前後軸（向前/向螢幕外為正，向後/深處為負）
- $Y \in [0, 195]$：垂直高度軸（$Y=0$ 為機台地板，$Y=195$ 為天車軌道頂部）

投影公式：
$$S_x = \text{round}\left(O_x + (X - Z) \times 1.10\right)$$
$$S_y = \text{round}\left(O_y + (X + Z) \times 0.55 - Y\right)$$
其中畫布原點基準設為 $O_x = W / 2$, $O_y = 285$。

### 2.2 深度排序（Z-Sorting & Depth Buffer）
在等角投影中，物體距離視點的距離由其 $X + Z$ 以及 $Y$ 共同決定。渲染清單依照 Depth Key 由小到大排序繪製：
$$\text{Depth} = (X + Z) \times 100 + Y$$
這保證了：
1. 後方的娃娃先畫，前方的娃娃後畫。
2. 下方的物體先畫，上方的物體疊加於其上。
3. 爪臂與爪中物體在運送時正確遮擋或被遮擋。

## 3. 高度自適應陰影投影（Height-Adaptive Shadow Projection）

為徹底解決 2.5D 深度對位痛點，設計**動態高度陰影吸附演算法**：

1. **射線向下碰撞檢測**：
   天車位於 $(C_x, C_y, C_z)$ 時，搜尋半徑 $|P_x - C_x| < R_p$ 且 $|P_z - C_z| < R_p$ 範圍內的所有娃娃。
2. **最高表面計算**：
   $$Y_{\text{surface}} = \max\left(0, \max_{p \in \text{under}}(p.y + p.r)\right)$$
3. **動態陰影渲染**：
   - 陰影繪製於投影座標 $\text{project}(C_x, Y_{\text{surface}}, C_z)$。
   - 若 $Y_{\text{surface}} > 0$，陰影自動微縮並加深透明度，呈現精準貼合於娃娃頭頂的圓斑！
   - 同時保留自天車頂部直射 $Y_{\text{surface}}$ 的**垂直紅色光學雷射瞄準虛線**。
   - **實戰效果**：玩家只要看到虛線與金色十字光圈落在娃娃頂部，下爪必定 100% 正中紅心！

## 4. 3D 剛體物理堆疊引擎（3D Rigid-Body Simulation）

### 4.1 3D 球體物理狀態
每隻娃娃具備獨立物理狀態：
$$\{x, y, z, v_x, v_y, v_z, r, w, \text{held}, \text{dropping}\}$$
固定物理步長 $\Delta t = 1/60\text{s}$：

### 4.2 娃娃與娃娃之間的 3D 碰撞
任兩隻非夾持狀態的娃娃 $A, B$：
$$\Delta x = B.x - A.x, \quad \Delta y = B.y - A.y, \quad \Delta z = B.z - A.z$$
$$d = \sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2}$$
若 $d < A.r + B.r$（發生重疊）：
1. **位置分離（Position Relaxation）**：
   $$\text{pen} = (A.r + B.r - d) \times 0.5$$
   $$A \gets A - \vec{n} \times \text{pen}, \quad B \gets B + \vec{n} \times \text{pen}$$
2. **法向與切向衝量（Impulse Response）**：
   計算相對速度並應用彈性係數（$e = 0.25$，軟質布偶低反彈）與切向摩擦力（$f = 0.85$），使娃娃自然在傾斜面上滾落並卡緊。

### 4.3 邊界約束
- 左/右壁：$X \in [-\text{BOX\_X} + r, \text{BOX\_X} - r]$
- 前/後壁：$Z \in [-\text{BOX\_Z} + r, \text{BOX\_Z} - r]$
- 地板：$Y \ge r$（若落入出貨口 $X \le \text{CHUTE\_X}$ 且 $Z \ge \text{CHUTE\_Z}$ 則不受地板限制，直接垂直墜落出貨）
