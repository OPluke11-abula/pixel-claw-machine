## 🎮 ゲームの主な特徴

- **ゼロ依存単一ファイル構造 (Zero-Dependency)**：
  - `index.html`（および 2.5D 版の `prototype_25d.html`）に完全完結。純粋な Canvas 2D 描画と Web Audio API による矩形波レトロサウンド。外部ライブラリ一切不要。
- **自作 2D 剛体物理エンジン**：
  - 天車（クレーン台車）の加速度が振り子の角速度と揺れを忠実に再現（本物の「アーム揺らし技」が可能）。
  - 円形剛体、すり抜け防止連続衝突判定（CCD）、カプセル形状アームによる押し出し判定、リアルな落とし口落下判定。
- **4 つのテーマ機台を自由に切り替え**：
  - 🧸 **動物ランド (Animal Paradise)**：クラシックな入門機台。コイン稼ぎに最適。
  - 💖 **ファンタジー (Dreamy Fantasy)**：軽量で幻想的。高弾性スライムや浮遊風船が集結。
  - ⚙️ **アイアンマシン (Iron Machinery)**：超重量級の高難度。鋼鉄ゴーレムや重力ブロックが立ちはだかる。
  - 🧪 **カオススライム (Mystic Slime)**：連鎖反応の嵐。高い反発係数とドミノ倒し押し出し。
- **3 段階の難易度階層と 95 個の景品山**：
  - **表層 (40個)**：標準的な初級小型ぬいぐるみ（$r=8$、重量 $1.0$）。
  - **中層 (35個)**：特殊効果を持つ中型景品（$r=11\sim 12$、謎の宝箱、爆弾衝撃波、引力星、浮遊風船、高弾力スライム）。
  - **深層底面 (20個)**：伝説の超巨大景品（$r=16\sim 17$、体積 4 倍、重量 $2.8\sim 4.0$）。アームサイズ改造後に捕獲可能。
- **🎁 謎の宝箱と 🚜 巨大パワーショベル (Excavator Mega Scoop)**：
  - **謎の宝箱 (Chest)**：中層の光る宝箱をゲットすると特殊能力が発動！次回のアームがド迫力の【🚜 重機パワーショベル】に変形！
  - **豪快な一網打尽**：幅広の工事用バケットで一度に 3〜7 個の景品をごっそりすくい上げ、落とし口へ一括投入して大量コインを獲得！
  - **ショップ販売**：ショップにて「ショベル改造券 (350🪙)」をいつでも購入可能。
- **6 種類の永久 RPG 機台改造**：
  - 🧵 **ワイヤー延長**：アームの最大下降深度を増加（底層の大型景品を狙う必須改造）。
  - ⚙️ **モーター強化**：基本アーム力を $+20\%$ 強化し、空中すっぽ抜けを軽減。
  - ⏳ **タイム延長**：1 プレイあたりの狙い時間を $+4\text{秒}$ 延長。
  - ⚡ **ハイスピードギア**：移動と昇降速度を $+15\%$ 高速化。
  - 🧤 **ジャイアントアーム**：**最重要改造！** アームの見た目と物理当たり判定を $+20\%$ 拡大し、伝説の巨大景品をガッチリ包み込む。
  - 🌟 **ラッキースター**：補充時にレア・伝説級景品の出現率が大幅上昇。
- **⚡ 二段手動アーム閉じ (Early Close / 途中閉じ)**：
  - 下降中にただ待つだけのもどかしさを解消！下降中はボタンが「🛑 合爪（閉じる）」に変化し、再度 `Space` キーまたはボタンを押すことで、任意の深さで即座にアームを閉じ、浮遊風船や高所の景品を空中迎撃可能！
- **🔥 FEVER TIME 連続獲得ラッシュ**：
  - 連続獲得（Combo $\ge 2$）でフィーバーモード突入！電飾が 2 倍速の 6 色レインボー回転を始め、落とし口に入るたびに大量ボーナスコイン（+25〜100🪙）が加算！
- **💰 レインボーコイン福袋 (Money Bag Jackpot)**：
  - 中層に常駐する特製福袋。落とし口へ運ぶと大爆発し、+160〜260 🪙 のコインジャックポットと全画面レインボー花火が炸裂！
- **快適な QOL と爽快な打撃感**：
  - ⏩ **2倍速モード**：キー `F` または画面ボタンで物理シミュレーションを瞬時に 2 倍速化。
  - 🔄 **3分間の機台再補充クールダウン**：景品を取り尽くしても、ボタン一つで 95 個を自然再補充。
  - 💥 **画面振動と重低音**：爆弾着地時に画面が微振動し、専用の矩形波爆発音が轟く。
  - 🎯 **レーザー照準線**：赤色点線レーザーが真下を照射し、視差によるズレをゼロに。
  - 🏆 **13 個の実績システム**：全種コンプリート、ショベルマスター、大富豪などやりこみ要素満載。
  - 🚨 **天井（確定ゲット）システム**：累積 300 円投入でアームが金色に輝き、100% 確実にゲット！

- **🎮 2.5D 等角投影 3D 立体版 (`prototype_25d.html`)**：
  - **4 方向空間照準**：WASD および矢印キーで前後（奥行き）と左右を精密操作。
  - **高さ適応型ダイナミックシャドウ (`getUnderSurfaceHeight`)**：アームの影が景品の山の高さに合わせて自動で頭頂部に吸着し、2.5D 特有の奥行き錯覚を完全排除！
  - **本物の 3D 剛体積み上げ物理**：60 個の立体景品が質量と摩擦を持ち、自然な山状に堆積。
  - **ネオ・アーケード筐体**：14 個のアニメーション電飾ランプ、アクリル反射光、立体落とし口、オーナー阿財（アーザイ）の台湾風ボイス吹き出し。
  - **8 種類の特製 3D 景品**：クマ、ウサギ、ヒヨコ、ネコ、カエル、宝箱、福袋、金色招き猫王。

## 🕹️ 操作方法とショートカットキー

### クラシック 2D 版操作
| アクション | キーボード | モバイル / タッチ |
|---|---|---|
| **コイン投入 (10コイン/回)** | `Enter` / `C` | 「投幣 10 元 (コイン投入)」をタップ |
| **クレーン左右移動** | `←` `→` または `A` `D` (長押し加速) | 仮想ボタン「◀」/「▶」を長押し |
| **アーム下降** | `Space` / `↓` | 仮想ボタン「下爪 (下降)」をタップ |
| **二段途中アーム閉じ** | 下降中: `Space` / `↓` | 「🛑 合爪 (閉じる)」をタップ |
| **2倍速切り替え** | `F` キー | 右上「▶ 1X / ⏩ 2X」をタップ |
| **テーマ切り替え** | 右上ドロップダウン | 右上ドロップダウン |
| **機台再補充 (リセット)** | 「🔄 重整機台 (補充)」をタップ | 「🔄 重整機台 (補充)」をタップ |
| **ミュート切り替え** | `M` キー | 「🔊 / 🔇」アイコンをタップ |

### 2.5D 等角投影版操作
| アクション | キーボード | モバイル / タッチ |
|---|---|---|
| **前後（奥行き）移動** | `W` (奥) / `S` (手前) または `↑` `↓` | D-pad「▲ 深入」/「▼ 靠前」をタップ |
| **左右水平移動** | `A` (左) / `D` (右) または `←` `→` | D-pad「◀ 往左」/「▶ 往右」をタップ |
| **アーム下降** | `Space` | 「🎯 下爪抓取 (下降)」をタップ |
| **二段途中アーム閉じ** | 下降中: `Space` | 「🛑 提前合爪 (途中閉じ)」をタップ |
| **2倍速切り替え** | `F` キー | 「⏩ 2X倍速」をタップ |
